# gentoo-overlay-bes

personal portage overlay

## Installing

add the overlay to gentoo:

```
$ emerge app-eselect/eselect-repository
$ eselect repository enable bes
```

update:

```
$ emaint sync -r bes
```

## Atoms

What each package changes or adds relative to the main `::gentoo` tree.

- sys-apps/busybox
  - keyworded `~arch` for 1.37.0, which `::gentoo` ships without keywords
  - `+extra` USE flag: keeps the applets stock switches off (beep, inetd, ipcalc, inotifyd, rfkill, ...)
- dev-perl/Mail-SPF
  - newer upstream (CPAN) release than `::gentoo`
  - patch: CNAME lookup failure fix
- mail-mta/exim
  - `experimental_spf` USE flag: SPF via Perl Mail::SPF (`EXPERIMENTAL_SPF_PERL`) instead of libspf2
  - `experimental_dmarc` USE flag: native DMARC (`EXPERIMENTAL_DMARC_NATIVE`, with PSL lookups)
  - patch: no direct `ld` for the dkim, dmarc and sieve_filter modules (bugs 976375, 982617); stock only patches dmarc and sieve_filter
  - keeps the `!dane? ( ssl? ( gnutls ) )` constraint (bug 925108) that stock's 4.100.1 ebuild dropped
- www-apps/gitea
  - newer upstream release than `::gentoo` (28.x)
  - adapted to 28.x: `gitea.dev` module path in the `-X` ldflags, `USE=sqlite` selects the cgo `sqlite_mattn` driver, cgo enabled for `pam`/`sqlite`
- sys-cluster/csync2 (not in `::gentoo`)
  - patch: abort on gnutls EAGAIN during large syncs
  - security patch: stack-use-after-scope in the pre-auth reply (LINBIT/csync2#49)
  - security patch: `get_tmpname()` buffer overflow (LINBIT/csync2#50)
- dev-util/diffr (not in `::gentoo`)
  - upstream release: diff tool with colorized word-level highlighting inside changed lines
- www-apps/gitea-runner-bin (not in `::gentoo`)
  - upstream prebuilt binary
  - installs a config generated by `gitea-runner config generate` as `/etc/gitea/gitea-runner-config.yaml`, updated through etc-update
- www-nginx/ngx-ja4 (not in `::gentoo`)
  - upstream release: JA4 TLS fingerprinting module for NGINX
